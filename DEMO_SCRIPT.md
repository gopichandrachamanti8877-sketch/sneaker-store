# Sprint 3 — Final Demonstration Walkthrough

**Estimated length:** 6–8 minutes (adjust for your course).

1. **Project overview (45 sec)** — Explain Sprint 1 foundation, Sprint 2 login/cart/checkout, and Sprint 3 final integration.
2. **Homepage (45 sec)** — Show the new visual identity, featured styles and category navigation.
3. **Catalogue (60 sec)** — Show 18 products, search, brand/category filters, sorting, availability.
4. **Product & bag (60 sec)** — Select a size, add to bag, change quantity, remove a line and show totals.
5. **Authentication (60 sec)** — Register using **fictional demo credentials**, log out, log back in, and show checkout gating.
6. **Simulated checkout (60 sec)** — Use fictional shipping details, select a demo payment method, confirm and show reference. State clearly: **no real money is processed**.
7. **Quality & evidence (60 sec)** — Show responsive mobile view, actual test results and Jira links SNEAK-32 through SNEAK-40.
8. **Wrap-up (30 sec)** — Summarize achieved criteria and future improvements (secure backend and real payment gateway would be separate production work).

## Presentation note

Never claim a feature has passed testing without recording an actual test run in `TESTING.md`.
